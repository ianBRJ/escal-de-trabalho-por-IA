# Escala de Funcionários

Projeto em Python com interface gráfica para montar uma escala de trabalho com foco em:

- definição do tipo de escala: dias de trabalho ou dias de folga
- separação entre sábado e domingo
- bloqueio de datas específicas para funcionários
- priorização de dias importantes com menos folgas
- dias menos importantes com mais folgas
- bloqueio específico de data para funcionário
- agrupamento de funcionários em grupos para coincidir dias de trabalho

## Como executar

```bash
cd "/home/ian/Área de trabalho/ian/prog/testes/escala_funcionarios"
python3 main.py
```

## Funcionalidades do programa

- Cadastrar funcionário
- Definir tipo global da escala
- Definir grupo para funcionário
- Bloquear dia específico
- Marcar dia importante
- Gerar escala por período
- Visualizar resultado em tela

## Observação

A aplicação usa a biblioteca padrão Tkinter, então não exige instalação de dependências extras.
